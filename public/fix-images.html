NFTGen Image Fix Utility

Fix NFT Images

This utility will fix known issues with NFT images in the NFTGen application. It will:

  • Fix "vande mataram" NFT images
  • Update localStorage with correct image URLs
  • Ensure NFTs display properly in the gallery and history
