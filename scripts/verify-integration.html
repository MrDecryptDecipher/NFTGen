NFTGen and Nija Wallet Integration Verification

This tool helps verify the integration between NFTGen and Nija Wallet by creating a mock NFT transaction and checking if it appears in the Transactions tab.

Instructions

  1. Make sure both NFTGen and Nija Wallet are running in the same browser
  2. Click the "Run Verification" button
  3. Check the output for logs and instructions
  4. Verify that the NFT transaction appears in the Transactions tab of Nija Wallet
  5. Click on the transaction to view its details
